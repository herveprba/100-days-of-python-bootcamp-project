## 💻 How to Run a Project Locally

1. Open your terminal or command prompt.
2. Clone this repository:
   ```bash
   git clone https://github.com/herveprba/100-days-of-python-bootcamp-project.git
   ```
3. Open the folder repository:
   ```bash
   cd 100-days-of-python-bootcamp-project
   ```
4. Navigate to the desired project folder:
   ```bash
   cd day-01-band-name-generator
   ```
5. Run the script:
   ```bash
   python main.py
   ```
